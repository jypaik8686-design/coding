# 띄워서 눈으로 확인

"될 것 같다"와 "된다" 사이에 이 스킬이 있다. 스크린샷을 보지 않고 다 됐다고 말하지 않는다.

## 1. 띄운다

```bash
python3 tools/serve.py 앱/<이름> --조용히 &
```

뜬 주소(기본 `http://127.0.0.1:8000/`)가 찍힌다. 8000번이 쓰이고 있으면 다음 번호로 간다.

`file://`로 바로 열어도 화면은 보이지만 서비스워커가 등록되지 않는다. 서버로 띄운다.

## 2. 찍는다

```bash
node tools/shot.mjs http://127.0.0.1:8000/ --out 화면/<이름>-목록.png
```

- `--전체` 스크롤 끝까지
- `--누르기 "<선택자>"` 눌러 본 뒤 찍기
- `--적기 "<선택자>=<값>"` 입력칸에 쳐 넣기
- `--심기 <json파일>` 열기 전에 localStorage를 채우기
- `--기기 "iPhone 14"` 플레이라이트 기기 이름으로
- `--엄격` 콘솔 오류가 있으면 exit 1

`--누르기`와 `--적기`는 준 순서대로 실행된다. 화면 한 장이 아니라 **흐름**을 확인할 때 쓴다.

```bash
node tools/shot.mjs http://127.0.0.1:8000/ \
  --누르기 ".tabs a[data-tab=add]" --적기 "#text=우유 사기" --누르기 "button[type=submit]" \
  --out 화면/넣은뒤.png
```

넣은 것이 목록에 보이면 저장까지 된 것이다. 화면만 보고 저장됐다고 치지 않는다.

## 3. 옛 데이터를 심고 본다

찍을 때마다 새 브라우저로 연다. **저장된 것이 하나도 없는 폰**이라는 뜻이다. 실제 폰에는 예전에 넣어 둔 데이터가 있다. 데이터 칸을 건드렸으면 옛 꼴을 심고 본다.

```json
{ "할일/v1": { "items": [ { "id": "a1", "text": "옛 항목", "done": true, "at": 1700000000000 } ] } }
```

```bash
node tools/shot.mjs http://127.0.0.1:8000/ --심기 화면/옛데이터.json --out 화면/옛데이터.png --엄격
```

키는 앱 `app.js`의 `KEY`와 같아야 한다. 새 칸이 없는 항목, 끝낸 항목, 작년 항목을 섞어 심는다. 빈 화면에서는 안 보이던 것이 여기서 나온다.

## 4. 콘솔을 읽는다

찍고 나면 콘솔 오류와 못 받아온 파일을 같이 찍어 준다. **`콘솔 깨끗함`이 나오지 않으면 화면이 멀쩡해 보여도 끝난 게 아니다.**

## 5. 스크린샷을 실제로 본다

찍은 PNG를 **읽어서 본다**. 보지 않고 "찍었음"만 말하는 건 확인이 아니다. 볼 것:

- 위쪽 바에 제목이 가려지지 않았는가
- 아래 탭이 본문을 덮지 않았는가
- 글자가 잘리거나 넘치지 않았는가
- 누를 것이 손가락만 한가 (44px)
- 상태마다 다르게 칠해져야 할 것이 엉뚱한 데까지 칠해지지 않았는가

## 6. 전후를 나란히 본다

```bash
node tools/shot.mjs --비교 화면/전.png 화면/후.png --out 화면/비교.png
```

고치기 전에 한 장 찍어 둔다. 고친 뒤에는 찍을 수 없다.

## 7. 이걸로 확인되지 않는 것

여기까지 통과해도 아래는 **확인된 게 아니다.** 보고할 때 확인 못 한 것으로 적는다.

| 확인 안 되는 것 | 이유 | 확인하려면 |
|---|---|---|
| 아이폰 사파리에서 되는지 | 찍는 브라우저는 크로미움이다 | 실제 아이폰에서 연다 |
| 키보드가 올라왔을 때 화면 | 키보드가 뜨지 않는다 | 실제 폰에서 입력칸을 눌러 본다 |
| 노치·홈 막대 둘레 여백 | 안전영역 값이 0으로 잡힌다 | 실제 폰에서 본다 |
| 서비스워커가 다음 방문에 하는 일 | 찍을 때마다 새 브라우저다 | 같은 브라우저로 두 번 열어 보는 시험을 따로 짠다 |
| 느린 망·끊긴 망 | 로컬 서버는 늘 빠르다 | 실제 폰에서 비행기 모드로 연다 |

## 8. 치우고 보고한다

```bash
kill %1    # 서버 끄기
```

`화면/`은 작업용이다. 저장소에 올라가지 않는다.

보고는 두 칸으로 나눈다.

- **확인한 것** — 찍어서 본 화면, 따라가 본 흐름, 콘솔 상태
- **확인 못 한 것** — 7번 표에서 이번 변경에 걸리는 줄
