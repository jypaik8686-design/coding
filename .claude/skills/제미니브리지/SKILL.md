# 제미니 브리지

양이 많고 판단이 가벼운 일은 제미니가 싸다. 결과만 받아서 쓴다.

## 넘기는 일 / 넘기지 않는 일

| 넘긴다 | 넘기지 않는다 |
|---|---|
| 문구 번역 50줄 | 어느 화면을 만들지 정하기 |
| 더미 데이터 200건 | 데이터 모양 정하기 |
| 문장 감정·분류 라벨 붙이기 | 코드 고치기 |
| 긴 문서 요약 | 사용자에게 뭘 물을지 정하기 |

판단이 걸린 일을 넘기면, 받은 결과를 검증하는 데 더 든다.

## 준비

```bash
export GEMINI_API_KEY=...   # https://aistudio.google.com/apikey
```

키가 없으면 도구가 어디서 받는지 알려 주고 멈춘다. 키를 저장소에 적지 않는다.

## 쓰기

```bash
python3 tools/gemini.py "이 문구 자연스러운 영어로: 넣기"
python3 tools/gemini.py --파일 앱/할일/명세.md "여기서 빠진 화면 찾아"
cat 긴글.md | python3 tools/gemini.py --시스템 "세 줄 요약만"
```

**한 줄씩 대량으로** — 이게 이 도구의 본값이다.

```bash
python3 tools/gemini.py --각줄 --시스템 "감정만 한 단어로" < 문장들.txt > 결과.tsv
```

줄마다 따로 물어보고 `입력<탭>답` 형식으로 뱉는다. 그대로 표에 붙는다.

## 먼저 예행한다

양이 많으면 돈이 든다. 보내기 전에 보낼 것을 본다.

```bash
python3 tools/gemini.py --예행 --각줄 < 문장들.txt
```

몇 번 물어보는지, 첫 줄이 무엇인지 찍어 준다. 200줄짜리를 실수로 두 번 돌리지 않게 한다.

## 모델 이름은 내려간다

기본 모델은 `tools/gemini.py` 맨 위 `기본모델`에 있다. 2026-11-12에 [공식 모델 목록](https://ai.google.dev/gemini-api/docs/models)에서 대량·저가용으로 적힌 것을 골랐다. `HTTP 404`가 나오면 이름이 내려간 것이다. 목록을 다시 보고 `--모델`로 바꾸고, 기본값도 고친다. 기억나는 이름을 그냥 넣지 않는다.

## 받은 것을 믿지 않는다

제미니가 준 것은 **확인 안 된 것**이다. 사실처럼 옮겨 적지 않는다.


- 결과를 파일에 쓸 때는 받은 그대로 쓰지 말고 눈으로 한 번 훑는다
- `[빈 답 — ...]`이 나오면 막혔거나 잘린 것이다. 프롬프트를 줄여 다시 한다
- 더미 데이터는 그럴듯한 거짓이다. 실제 값으로 쓰지 않는다
