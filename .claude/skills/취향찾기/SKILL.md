# 취향찾기

파일을 훑는 건 도구, 공통점을 판단하는 건 세션, 적을지 정하는 건 사용자다.

## 1. 훑을 곳 정하기

세션에 붙은 메모 저장소에서 고른다. 경로를 지어내지 말고 `ls`로 확인한다.

- **바깥**: 서가, 아이디어 보관소, 입고 기록, 그림 작업 기록(`기록.md`) 같은 곳
- **안쪽**: 일기, 감정배설, 진료. 사용자가 읽으라고 정했다 (2026-11-17). `--안쪽`으로 따로 넘긴다
- **이미**: 지금 쓰고 있는 취향 파일. `--이미`로 넘겨 이미 적힌 줄은 빼게 한다

## 2. 돌리기

```bash
python3 tools/taste_scan.py <바깥 폴더>... --안쪽 <안쪽 폴더>... --이미 <취향 파일>... [--부터 YYYY-MM-DD]
```

지난번에 훑은 날이 취향 파일에 있으면 `--부터`로 그 뒤만 본다.

## 3. 공통점 판단

- 낱말 표는 실마리일 뿐이다. 낱말이 여러 파일에 나오면 그 파일들을 열어 같은 결인지 본다.
- "좋고 싫음이 드러난 줄"에서 같은 방향의 줄이 **두 군데 넘게** 나오면 공통점 후보다. 한 번 나온 것은 취향이라 부르지 않는다.
- 후보마다 근거 파일:줄을 둘 이상 붙인다. 근거 없는 후보는 내지 않는다.
- 제미니나 다른 외부 AI에 넘기지 않는다. 안쪽 글이 섞여 있다.

## 4. 제안하고 고르게 하기

후보를 칸으로 나눠 `[가안]` 꼴로 보여 준다. 사용자가 고르기 전에는 한 줄도 적지 않는다.

| 칸 | 어디서 나온 것 | 적는 곳 |
|---|---|---|
| 그림 취향 | 그림·디자인 관련 | 그림 취향 파일의 좋아하는 것 / 싫어하는 것 |
| 글·이야기 취향 | 서가·보관소·원고 | 메모 저장소 사서참고의 `## 취향` 칸 |
| 사적인 것 | 근거에 **안쪽이 하나라도** 있음 | 사서참고의 `## 개인 (벽 안쪽)` 칸에만 |

- 근거에 안쪽이 섞인 후보는 바깥 칸에 쓰지 않는다. 바깥 칸은 그림 프롬프트나 다른 저장소로 넘어가기 때문이다.
- 대답에서도 안쪽 근거는 파일:줄만 적고 원문을 길게 옮기지 않는다.

## 5. 적기

- 고른 것만 `- 내용 (취향찾기 YYYY-MM-DD)` 꼴로 적는다. 시각은 `date '+%F'`로 본다.
- 사용자가 거부한 후보는 적지 않는다. 같은 후보를 다음에 다시 내지 않도록 대답에 "거부: …" 한 줄을 남긴다.
- 적은 저장소에 점검 도구가 있으면 돌린다.
