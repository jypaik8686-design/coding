# 내놓기

파일 경로와 PR 링크는 결과물이 아니다. 사용자가 폰에서 눌러 여는 주소가 결과물이다.

## 0. 줄 수 있는 주소가 있는지 먼저 본다

```bash
python3 tools/ready.py     # '앱 주소' 줄을 본다
```

| '앱 주소' 줄 | 뜻 | 할 일 |
|---|---|---|
| ✓ 전부 올라가 있음 | 주소가 살아 있고 앱이 다 나와 있다 | 4번으로 가서 주소를 건넨다 |
| ✓ 주소에 아직 없는 앱: … | 주소는 살아 있는데 이 앱이 아직 안 올라갔다 | 1번부터 한다 |
| ✗ 꺼져 있음 | 사용자가 주소를 아직 켜지 않았다 | **대답 첫 문장에서** "아직 폰에서 열 주소가 없다"고 말하고, 맨 아래 '주소 켜기'를 그대로 안내한다. 켜는 것은 사용자만 할 수 있다 |

꺼져 있어도 1~3번은 해 둔다. 켜지는 순간 바로 열리게.

## 1. 내놓기 전에

- `눈으로확인`을 통과했다. 콘솔이 깨끗하고, 옛 데이터를 심은 상태에서도 봤다.
- `명세.md`의 '한 줄'이 채워져 있다. 서랍에 그대로 나온다.
- **앱 안에 열쇠를 적지 않았다.** 주소는 누구나 열 수 있다. 열쇠가 필요한 앱은 사용자가 자기 폰의 설정 화면에서 넣게 만든다.

## 2. 서랍을 다시 만든다

```bash
python3 tools/drawer.py
python3 tools/check_toolbox.py
```

서랍은 저장소 맨 위 `index.html`이다. 주소로 들어오면 처음 보이는 화면이고, 앱 목록이 거기서 나온다.

## 3. 올린다

커밋하고, 푸시하고, PR을 만든다. **기본 가지에 병합돼야 주소에 나온다.** 병합은 사용자가 한다. 사용자가 병합하라고 하면 한다.

## 4. 주소를 건넨다

대답 첫머리에 이 꼴로 준다.

```
앱 주소: https://<계정>.github.io/<저장소>/앱/<이름>/
```

- 주소의 앞부분은 `ready.py`의 '앱 주소' 줄에 나온 것을 그대로 쓴다. 지어내지 않는다.
- 병합 전이면 "PR을 병합하고 1~2분 뒤에 열린다"고 같이 말한다. 지금 열리는 것처럼 말하지 않는다.
- 병합됐다고 하면 `ready.py`를 다시 돌려 '전부 올라가 있음'을 보고 나서 열린다고 말한다.
- 홈 화면에 추가해 두면 앱처럼 열린다고 한 줄 붙인다. 아이폰은 그래야 저장된 것이 7일 뒤에 지워지지 않는다.

## 이 길로 안 되는 것

| 안 되는 것 | 이유 |
|---|---|
| 주소를 비밀로 하기 | 저장소가 비공개여도 주소는 누구나 열 수 있다 ([GitHub 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), 2026-11-12 확인). 남이 보면 안 되는 것을 앱 파일에 넣지 않는다 |
| 클로드 아티팩트로 대신 내놓기 | 아티팩트 안에서는 다른 서버로 가는 요청이 막힌다. 제미니처럼 밖의 API를 부르는 앱은 거기서 돌지 않는다 (아티팩트 도구 설명, 2026-11-12 확인) |
| 병합 없이 주소에 올리기 | 주소는 기본 가지의 파일을 내보낸다 |

## 주소 켜기 (사용자가 한 번만)

메뉴 이름은 GitHub 문서에 적힌 그대로다 (2026-11-12 확인). 화면이 다르면 다르다고 말하고, 사용자에게 보이는 대로 알려 달라고 한다.

**먼저 정할 것.** GitHub Pages는 무료 요금제에서는 공개 저장소에서만 켜진다. 비공개인 채로 쓰려면 GitHub Pro 이상이 필요하다. 저장소를 공개하면 규칙, 도구, 앱 코드를 누구나 볼 수 있다. 열쇠는 저장소에 없으므로 새어 나가지 않는다.

1. **(무료 요금제면) 저장소를 공개로** — 저장소 → `Settings` → 맨 아래 `Danger Zone` → `Change repository visibility` 오른쪽의 `Change visibility` → 공개 선택 → `I have read and understand these effects` → `Make this repository public`
2. **주소 켜기** — `Settings` → 옆 메뉴의 `Pages` → `Build and deployment` 아래 `Source`에서 `Deploy from a branch` → 가지는 기본 가지, 폴더는 `/ (root)` → `Save`
3. 1~2분 뒤 `python3 tools/ready.py`의 '앱 주소' 줄이 ✓로 바뀌는지 본다.
