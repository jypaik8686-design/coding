# 취향뽑기 — 명세

## 한 줄

이번 장면만 적으면 내 취향 태그를 늘 붙여 NovelAI로 한 장 뽑고, 참조 이미지(Vibe Transfer)로 분위기를 따라 한다.

## 데이터 모양

- localStorage `취향뽑기/v1`: scene / style / neg / q / token / model / size / steps / scale
- localStorage `취향뽑기/vibes`: `"<이미지 sha>:<모델>"` → encode-vibe 결과(base64). 8개를 넘으면 오래된 것부터 버린다
- 참조 이미지 원본과 뽑은 그림은 저장하지 않는다 (새로 고치면 사라진다. 그림은 '저장'으로 받는다)

## 화면

한 화면. 이번 장면 → 참조 이미지(최대 4장, 장마다 강도) → 내 취향대로 만들기. 접힌 칸: 내 취향, 설정(토큰·모델·크기·스텝·강도), 마지막으로 보낸 프롬프트.

## 밖에 나가는 것

- `POST https://image.novelai.net/ai/encode-vibe` — 새 참조 이미지마다 한 번. 장당 2 Anlas ([nekoai-api README](https://github.com/nya-foundation/nekoai-api), 2026-11-16 읽음)
- `POST https://image.novelai.net/ai/generate-image` — 몸통은 짤뽑기와 같고, `reference_image_multiple`에 encode-vibe 결과를 넣는다. V4.5에 원본 이미지를 그대로 넣으면 무시된다 ([marinara-engine #2122](https://github.com/pasta-devs/marinara-engine/issues/2122), 2026-11-16 읽음)
- 두 주소 모두 브라우저 직접 호출을 받는다: 사전 요청에 `access-control-allow-origin: *` (2026-11-16 curl로 확인)
- 진짜 토큰으로 그림이 나오는 것과 V5에서 참조 이미지가 되는지는 돌려 보지 못했다. 가짜 서버로 흐름만 확인했다

## 안 하는 것

- 보관함, 기록, 여러 장 한꺼번에, 자동 재시도
- Precise Reference(Director Reference), 이미지로 이미지, 인페인트
- 29스텝 이상 (Anlas가 드는 범위)
