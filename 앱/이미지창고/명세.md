# 이미지창고 — 명세

## 한 줄

폰 갤러리 그림을 모아 두고 태그를 붙여, 태그로 골라 보고 한꺼번에 정리하는 이미지 창고.

## 데이터 모양

그림은 크기가 커서 localStorage(약 5MB)에 못 넣는다. 원본과 썸네일은 IndexedDB `이미지창고`, 화면 설정만 localStorage `이미지창고/v1/ui`.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| IndexedDB `meta` | id / hash / name / type / size / w / h / tags[] / memo / at / nai? | 그림 한 장의 정보. hash(SHA-256)로 같은 그림을 두 번 넣지 않는다. nai는 NovelAI PNG만 있음(prompt / uc / chars[{text,neg}] / params / model), 옛 항목엔 없음 |
| IndexedDB `blob` | id / full / thumb | 원본 Blob, 긴 변 360px 썸네일(webp, 안 되면 jpeg) |
| localStorage drive | apiKey / clientId / appId | 구글 드라이브 고르기에 쓰는 값. 사용자가 설정에서 넣음, 저장소에는 없음 |
| localStorage ui | cols / sort / tagSort / naiTags | 한 줄 장수(2~5), 새 것부터·옛 것부터, 태그 화면 순서, NovelAI 프롬프트를 태그로 붙일지(처음 켬) |

NovelAI 프롬프트 → 태그: 바탕 프롬프트와 인물별 프롬프트를 쉼표·`|`로 나누고, `{}`·`[]`·`()`와 `1.2::…::` 가중치를 떼고, `_`는 띄어쓰기로. 품질 태그(masterpiece·very aesthetic·no text 등), 인원수(1girl·2girls·solo), 인물 칸 머리말(girl·boy·other)은 뺀다. 한 장에 60개까지, `novelai` 태그를 같이 붙인다. PNG 읽기는 `../해체기/risu.js`의 `naiInfo`(짤뽑기와 같은 코드).

태그는 앞뒤 공백·`#`를 떼고, 가운데 공백은 하나로, 영문은 소문자로 다듬는다. 쉼표로 여러 개.

|---|---|---|---|

| 한 장 | `#/img/<id>` | 원본 보기, 이전·다음(옆으로 밀기), 태그 더하기·떼기, 메모, NovelAI 생성 정보(접는 칸: 프롬프트·인물별·빼는 것 칸마다 복사, 시드·스텝·강도·샘플러·크기·모델, ‘프롬프트를 태그로 붙이기’), 원본 내려받기, 지우기 | meta, blob |

## 밖에 나가는 것

구글 드라이브에서 고를 때만 나간다. 그 밖에는 없다.

- `https://accounts.google.com/gsi/client`, `https://apis.google.com/js/api.js`: 드라이브 버튼을 처음 누를 때만 불러온다
- 로그인: Google Identity Services 토큰, 권한은 `drive.file`(피커에서 고른 파일만 열 수 있음). 토큰은 메모리에만 두고 1시간쯤 뒤에 다시 받는다
- Google Picker로 고르고 `GET https://www.googleapis.com/drive/v3/files/<id>?alt=media`로 받는다. 받은 그림은 ‘넣기’의 고른 목록에 들어가 갤러리 그림과 똑같이 넣는다
- 근거: developers.google.com/workspace/drive/picker/guides/web-picker-sample (2026-09-03 갱신본). 구글 클라우드에서 Picker API·Drive API 켜기, API 키(웹사이트 제한에 앱 주소와 `https://docs.google.com/*`), OAuth 클라이언트 ID(웹 애플리케이션, 승인된 자바스크립트 원본에 앱 주소), 프로젝트 번호가 필요하다

그림은 이 기기 이 브라우저에만 있다. 백업 ZIP은 무압축(STORE)으로 쓰고 `meta.json`에 태그·메모를 담는다. 읽을 때는 무압축과 deflate ZIP을 받는다(그냥 그림 ZIP도 그림만 넣음).

## 안 하는 것

- 로그인, 서버 저장, 여러 기기 맞춤 (옮길 때는 ZIP 백업)
- 드라이브에 올리기·드라이브와 맞추기, 드라이브 폴더 통째로 가져오기(drive.file 권한으로는 고른 파일만 열림)
- 공유 메뉴로 받기(Share Target), 클립보드 붙여넣기
- 그림 편집, AI로 그림을 보고 태그 달기
- RisuAI 카드·.charx 안 그림 꺼내기, NovelAI 외 생성기(Stable Diffusion 등) 정보 읽기
- HEIC처럼 브라우저가 못 여는 형식의 썸네일 (원본은 보관하고 내려받기는 됨)
