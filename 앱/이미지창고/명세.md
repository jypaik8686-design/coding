# 이미지창고 — 명세

## 한 줄

폰 갤러리 그림을 모아 두고 태그를 붙여, 태그로 골라 보고 한꺼번에 정리하는 이미지 창고.

## 데이터 모양

그림은 크기가 커서 localStorage(약 5MB)에 못 넣는다. 원본과 썸네일은 IndexedDB `이미지창고`, 화면 설정만 localStorage `이미지창고/v1/ui`.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| IndexedDB `meta` | id / hash / name / type / size / w / h / tags[] / memo / at | 그림 한 장의 정보. hash(SHA-256)로 같은 그림을 두 번 넣지 않는다 |
| IndexedDB `blob` | id / full / thumb | 원본 Blob, 긴 변 360px 썸네일(webp, 안 되면 jpeg) |
| localStorage ui | cols / sort / tagSort | 한 줄 장수(2~5), 새 것부터·옛 것부터, 태그 화면 순서 |

태그는 앞뒤 공백·`#`를 떼고, 가운데 공백은 하나로, 영문은 소문자로 다듬는다. 쉼표로 여러 개.

## 화면

| 화면 | 주소 | 하는 일 | 쓰는 데이터 |
|---|---|---|---|
| 창고 | `#/list` | 썸네일 격자. 찾기(태그·이름·메모), 태그 칩 누르면 고름 → 한 번 더 누르면 뺌 → 풀림(여러 개는 AND), ‘태그 없음’만 보기. ‘고르기’나 길게 눌러 여러 장 골라 태그 붙이기·떼기·지우기 | meta |
| 넣기 | `#/add` | 갤러리에서 여러 장 고르고, 같이 붙일 태그 정해 넣기. 진행 막대 | meta, blob |
| 태그 | `#/tags` | 태그 전부와 장수, 많은 순·가나다순, 누르면 그 태그로 창고. 이름 바꾸기(있는 이름이면 합침), 지우기(그림은 남김) | meta |
| 설정 | `#/settings` | 한 줄 장수, 순서, 쓴 공간, 브라우저가 지우지 않게 요청(`navigator.storage.persist`), ZIP 백업·되살리기, 태그 JSON, 전부 지우기 | 전부 |
| 한 장 | `#/img/<id>` | 원본 보기, 이전·다음(옆으로 밀기), 태그 더하기·떼기, 메모, 원본 내려받기, 지우기 | meta, blob |

## 밖에 나가는 것

없음. 그림은 이 기기 이 브라우저에만 있다. 백업 ZIP은 무압축(STORE)으로 쓰고 `meta.json`에 태그·메모를 담는다. 읽을 때는 무압축과 deflate ZIP을 받는다(그냥 그림 ZIP도 그림만 넣음).

## 안 하는 것

- 로그인, 서버 저장, 여러 기기 맞춤 (옮길 때는 ZIP 백업)
- 공유 메뉴로 받기(Share Target), 클립보드 붙여넣기
- 그림 편집, 자동 태그(AI)
- HEIC처럼 브라우저가 못 여는 형식의 썸네일 (원본은 보관하고 내려받기는 됨)
