# 돌려보기 — 명세

## 한 줄

폰에서 사진이나 그림 한 장을 고르면 깊이를 계산해 손가락·기울기로 입체처럼 돌려 보는 앱.

## 데이터 모양

저장하는 항목 없음. 사진은 저장하지 않고 화면에서만 쓴다.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| settings | 세기 (localStorage `돌려보기:세기`) | 시점 이동 세기. 0.02~0.14 |

## 화면

화면 하나. 사진이 없으면 고르기 안내, 있으면 그림과 조작.

| 상태 | 하는 일 | 쓰는 것 |
|---|---|---|
| 비어 있음 | 사진 고르기 버튼 | 파일 선택 |
| 보는 중 | 끌어서 돌리기, 세기 슬라이더, 기울여 보기, 깊이 보기, 다른 사진 | 깊이맵, WebGL |

## 밖에 나가는 것

- 깊이 모델 `Xenova/depth-anything-small-hf`(약 27MB)와 실행 코드(transformers.js, onnxruntime)를 jsdelivr와 huggingface.co에서 받는다. 처음 한 번, 이후 브라우저가 저장.
- 사진은 밖으로 나가지 않는다.

## 안 하는 것

- 사진 업로드·서버 저장·공유
- 3D 모델 파일(.glb) 내보내기 — 이건 깊이 한 장으로 시점을 어긋나게 그리는 것이지 메시가 아니다
- 뒷면 만들기 — 보이는 면 기준 작은 각도만 돈다
- 모델을 못 받으면 근사 깊이로 대신 돌아간다(정확도 낮음)
