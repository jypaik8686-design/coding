# 짤뽑기 — 명세

## 한 줄

취향 프롬프트를 늘 붙여 NovelAI로 그림을 한 장씩 뽑고, 보관한 것과 버린 것에서 취향 태그를 쌓는다. V4.5에서는 참고 그림(바이브)을 붙일 수 있고, 장면은 프롬프트 비서(제미니)와 말로 짠다.

## 데이터 모양

`app.js`의 `SHAPE()`와 같아야 한다. 글자는 localStorage(`짤뽑기/v1`), 그림은 IndexedDB(`짤뽑기` v2 / `img`, `ref`). `KEY`는 그대로 `v1`: 새 칸은 전부 더하기만 했고 옛 칸의 뜻은 안 바뀌었다.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| settings | token / model / customModel / size / steps / scale / quality / aiKey / aiModel / aiCustom | NovelAI 토큰과 생성 값. size는 세로·가로·정사각. aiKey는 제미니 키, aiModel은 `assistant.js`의 `MODEL_CHOICES` 중 하나 또는 `custom`(이름은 aiCustom). 옛 데이터에는 ai 칸이 없어 `load()`가 기본값으로 메운다 |
| taste | style / negative / seeded | 늘 붙는 취향 프롬프트(처음 값은 `DEFAULT_STYLE` = art `프롬프트/NAI.md`의 키아나 그림체 블록), 빼는 것(처음 값은 NovelAI 문서의 Human Focus V5 Full). seeded는 style 처음 값을 이미 넣었다는 표시 — 옛 데이터에서 style이 비어 있으면 한 번만 채운다 |
| draft | scene / seedLock / seed / seeded | 쓰다 만 이번 그림, 시드 고정 여부, 마지막 시드. 처음엔 scene이 `DEFAULT_SCENE`(정장·중국식 미인·금발을 옮긴 태그)으로 채워져 있다. seeded는 이 기본값을 이미 넣었다는 표시 |
| log[] | id / scene / style / negative / seed / model / w / h / steps / scale / at / verdict / refs? | 뽑은 기록 하나. verdict는 null·keep·drop. 400건을 넘으면 보관 아닌 것부터 지운다. refs는 이 그림에 쓴 참고 그림 `[{s: 강도, i: 정보량}]`이고 옛 항목에는 없다(읽을 때 `?.`로 0장 취급) |
| chat[] | role / text / at | 비서와 한 대화. role은 user·model. 40개를 넘으면 앞에서부터 버린다. 내보내기에는 들어가고 제미니 키는 빠진다 |
| (IndexedDB) img | id / full / thumb | 보관한 그림의 PNG 원본과 360px 썸네일. id는 log의 id |
| (IndexedDB) ref | id / name / at / on / strength / info / full / thumb / enc | 참고 그림. full은 긴 변 1024px 이하 PNG, strength는 0~1(처음 0.6), info(정보량)는 0~1(처음 1), on은 이번에 쓰는지. enc는 `{"<모델>\|<정보량>": 인코딩 결과(base64)}`로, 같은 그림·모델·정보량이면 서버에 다시 안 묻는다. 최대 4장(이 앱이 정한 한도) |

## 화면

| 화면 | 주소 | 하는 일 | 쓰는 데이터 |
|---|---|---|---|
| 뽑기 | `#/gen` | 이번 그림 태그를 적고 한 장 뽑기. 참고 그림 붙이기(V4.5 계열 모델일 때만 보임: 쓰기·강도·정보량·빼기). 보관·버림·저장 | draft, settings, taste, log, ref |
| 비서 | `#/ai` | 장면을 한국어로 말하면 제미니가 NovelAI 태그 프롬프트를 짠다. 코드 블록 아래 ‘이번 그림에 넣기’·‘빼는 것에 더하기’·‘복사’, 사전에 없거나 게시물이 적은 태그 표시 | chat, settings, taste, draft |
| 보관함 | `#/keep`, `#/keep/<id>` | 보관한 그림 격자, 한 장 보기, 이 설정으로 다시, 지우기 | log, img |
| 취향 | `#/taste` | 취향 프롬프트, 빼는 것, 자주 고른 태그, NovelAI 토큰·모델·스텝, 제미니 키·모델, 내보내기, 전부 지우기 | taste, settings, log |

## 밖에 나가는 것

- NovelAI: `POST https://image.novelai.net/ai/generate-image`, 그리고 참고 그림이 있을 때만 `POST https://image.novelai.net/ai/encode-vibe`. 토큰은 `Authorization: Bearer`로 이 서버에만 간다.
- 제미니: `POST https://generativelanguage.googleapis.com/v1beta/models/<모델>:generateContent`. 키는 `x-goog-api-key` 머리글로 이 서버에만 간다. 비서에게 보낸 대화, 취향 프롬프트, 현재 이번 그림 칸, 비서 지시문이 구글로 나간다. 이 서버가 브라우저 직접 호출을 허용하는 것은 사전 요청으로 확인했다(2026-11-18, `access-control-allow-origin`이 요청 출처를 되돌려 줌).
- 이 서버는 브라우저 직접 호출을 받는다: 사전 요청에 `access-control-allow-origin: *`, 허용 헤더 `Authorization, Content-Type` (2026-11-15 curl로 확인).
- 요청 몸통은 V5에서 200이 확인된 꼴을 그대로 쓴다. `v4_prompt`·`v4_negative_prompt`를 빼면 500. 응답은 `image_0.png`가 든 zip ([측정 글](https://dev.to/ilan_kim/calling-the-novelai-v5-api-directly-nai-diffusion-5-full-request-body-paramsversion-4310-133a), 2026-11-15 읽음). 틀린 토큰은 `401 Unauthorized` (2026-11-15 curl로 확인).
- 품질 태그 문구는 [NovelAI 문서](https://docs.novelai.net/en/image/qualitytags/) 그대로. 서버 토글(`qualityToggle`)은 끄고 앱이 직접 붙인다.
- 참고 그림(V4.5 바이브): 그림을 `/ai/encode-vibe`에 `{image(base64 PNG), information_extracted, model}`로 보내면 이진 파일이 오고(2026-11-18 200 확인, 문서에는 201), 이것을 base64로 바꿔 `reference_image_multiple`에, 정보량을 `reference_information_extracted_multiple`에, 강도를 `reference_strength_multiple`에 같은 순서로 넣는다. 이 꼴로 V4.5 Full에서 한 장이 나왔고 참고 그림의 검정·금테가 결과에 따라왔다(세션에서 `curl`로 확인). 인코딩 비용 2 Anlas는 문서 기준이고 실제 차감은 재 보지 않았다.
- V5(`nai-diffusion-5-full`)는 참고 그림이 서버에서 거절된다(art 확인 2026-11-17). 그래서 모델이 V5이면 붙여 둔 그림이 있어도 안 보낸다.
- 비서가 쓰는 제미니 모델은 2026-11-18 이 키로 직접 불러 200을 받은 것만 고르기에 둔다(`gemini-flash-latest`, `gemini-3.8-flash`, `gemini-3.1-pro-preview`). `gemini-2.5-flash`와 `2.5-pro`는 모델 목록에는 있는데 호출하면 "새 사용자에게는 더 안 열림"으로 404였다. 사용자 키에서는 다를 수 있어 ‘직접 입력’을 둔다.
- 비서 지시문(`assistant.js`)은 art 저장소의 `취향.md`, `프롬프트/NAI.md`, `프롬프트/NAI사용법.md`에서 그림 프롬프트 만들기만 옮긴 것이다(2026-11-18). art가 바뀌어도 자동으로 안 따라온다.
- 태그 사전(`tags.json`, 약 430KB·압축 170KB)은 art `태그사전/`의 일반 태그(게시물 100개 이상 17,267개)와 한국어 이름 2,163개를 옮긴 것이다. 비서 화면을 처음 쓸 때 한 번 받는다. 한국어 낱말이 들어 있으면 그 태그를 ‘사전 후보’로 제미니에 붙이고, 비서가 낸 scene 블록의 태그는 사전과 맞춰 없는 것·1000개 미만인 것을 알린다. 캐릭터·작가 이름과 `young adult woman` 같은 문장형 문구는 일반 태그에 없어서 ‘사전에 없음’으로 나온다.
- 진짜 토큰으로 이 앱의 화면에서 그림이 나오는 것은 돌려 보지 못했다. 가짜 서버로 흐름을 확인했고, 요청 꼴은 세션에서 `curl`로 따로 확인했다.

## 안 하는 것

적어 두면 나중에 흔들리지 않는다.

- 로그인, 서버 저장, 기기 사이 동기화
- 여러 장 한꺼번에, 자동 반복, 자동 재시도 (NovelAI는 사람이 누른 요청만 허용하고 429에 재시도를 금한다)
- 29스텝 이상, 큰 크기 (Anlas가 드는 범위)
- 이미지로 이미지, 인페인트, 정밀 참조(캐릭터 레퍼런스, 바이브와 같이 못 씀), 인물별 프롬프트
- 참고 그림을 보관한 그림에 묶어 다시 뽑기에 따라오게 하기 (다시 뽑기는 장면·시드만 되돌림)
- 비서에게 그림 보내기, 비서 답을 자동으로 뽑기에 넣기(눌러야 들어감), 스트리밍 답, 비서가 취향 프롬프트를 직접 고치기
- 제미니 말고 다른 AI (Claude는 API 키·과금이 따로라 이번엔 뺌)
- 토큰을 내보내기 파일에 넣기
