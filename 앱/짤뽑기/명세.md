# 짤뽑기 — 명세

## 한 줄

취향 프롬프트를 늘 붙여 NovelAI로 그림을 한 장씩 뽑고, 보관한 것과 버린 것에서 취향 태그를 쌓는다.

## 데이터 모양

`app.js`의 `SHAPE()`와 같아야 한다. 글자는 localStorage(`짤뽑기/v1`), 그림은 IndexedDB(`짤뽑기` / `img`).

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| settings | token / model / customModel / size / steps / scale / quality | NovelAI 토큰과 생성 값. size는 세로·가로·정사각 |
| taste | style / negative / seeded | 늘 붙는 취향 프롬프트(처음 값은 `DEFAULT_STYLE` = art `프롬프트/NAI.md`의 키아나 그림체 블록), 빼는 것(처음 값은 NovelAI 문서의 Human Focus V5 Full). seeded는 style 처음 값을 이미 넣었다는 표시 — 옛 데이터에서 style이 비어 있으면 한 번만 채운다 |
| draft | scene / seedLock / seed / seeded / refStrength | 쓰다 만 이번 그림, 시드 고정 여부, 마지막 시드. 처음엔 scene이 `DEFAULT_SCENE`(정장·중국식 미인·금발을 옮긴 태그)으로 채워져 있다. seeded는 이 기본값을 이미 넣었다는 표시. refStrength는 참조 강도(0.05~0.95, 처음 0.6) — 옛 데이터에는 없어서 `load()`의 펼치기가 0.6으로 메운다 |
| log[] | id / scene / style / negative / seed / model / w / h / steps / scale / at / verdict | 뽑은 기록 하나. verdict는 null·keep·drop. i2i는 참조 그림을 썼을 때만 있는 강도(없으면 참조 없이 뽑은 것). 400건을 넘으면 보관 아닌 것부터 지운다 |
| (IndexedDB) img | id / full / thumb | 보관한 그림의 PNG 원본과 360px 썸네일. id는 log의 id |

## 화면

| 화면 | 주소 | 하는 일 | 쓰는 데이터 |
|---|---|---|---|
| 뽑기 | `#/gen` | 이번 그림 태그를 적고 한 장 뽑기. 참조 그림 넣기(＋ 참조 그림 넣기 → 강도 막대 → 참조 빼기). 보관·버림·저장 | draft, settings, taste, log |
| 보관함 | `#/keep`, `#/keep/<id>` | 보관한 그림 격자, 한 장 보기, 이 설정으로 다시, 지우기 | log, img |
| 취향 | `#/taste` | 취향 프롬프트, 빼는 것, 자주 고른 태그, 토큰·모델·스텝, 내보내기, 전부 지우기 | taste, settings, log |

## 밖에 나가는 것

- `POST https://image.novelai.net/ai/generate-image` 하나뿐. 토큰은 `Authorization: Bearer`로 이 서버에만 간다.
- 이 서버는 브라우저 직접 호출을 받는다: 사전 요청에 `access-control-allow-origin: *`, 허용 헤더 `Authorization, Content-Type` (2026-11-15 curl로 확인).
- 요청 몸통은 V5에서 200이 확인된 꼴을 그대로 쓴다. `v4_prompt`·`v4_negative_prompt`를 빼면 500. 응답은 `image_0.png`가 든 zip ([측정 글](https://dev.to/ilan_kim/calling-the-novelai-v5-api-directly-nai-diffusion-5-full-request-body-paramsversion-4310-133a), 2026-11-15 읽음). 틀린 토큰은 `401 Unauthorized` (2026-11-15 curl로 확인).
- 품질 태그 문구는 [NovelAI 문서](https://docs.novelai.net/en/image/qualitytags/) 그대로. 서버 토글(`qualityToggle`)은 끄고 앱이 직접 붙인다.
- 진짜 토큰으로 그림이 나오는 것은 이 저장소에서 돌려 보지 못했다. 가짜 서버로 흐름만 확인했다.

## 참조 그림 (이미지로 이미지)

- 뽑기 화면에서 그림 파일 하나를 고르면 뽑을 크기(w×h)에 꽉 차게 잘라 PNG로 만들어 `action: "img2img"`, `parameters.image`(base64), `strength`(참조 강도), `noise: 0`으로 보낸다. 참조가 없으면 지금까지와 같다.
- **V5(`nai-diffusion-5-full`)에서 된다.** 2026-11-18 curl로 같은 몸통을 보냈고 HTTP 200에 PNG가 왔다. 참조로 넣은 그라데이션의 색 배치(왼쪽 위 파랑·오른쪽 위 자주·왼쪽 아래 초록·오른쪽 아래 노랑)를 출력이 따라갔다. 바이브 트랜스퍼·정밀 참조는 V5에서 막혀 있어(art `프롬프트/NAI사용법.md`) 이 길만 쓴다.
- 참조 그림은 **메모리에만** 둔다. 새로 고치면 사라지고, 보관함 ‘다시 뽑기’에도 따라오지 않는다. log에는 강도(`i2i`)만 남는다.
- 강도의 뜻(작을수록 원본에 가깝다는 방향)은 NovelAI 문서에서 확인하지 않았다. 앱 화면 문구는 내가 curl로 본 한 장(0.6)과 일반적인 img2img 동작에 맞춘 것이다.
- Anlas가 더 드는지는 미확인.

## 안 하는 것

적어 두면 나중에 흔들리지 않는다.

- 로그인, 서버 저장, 기기 사이 동기화
- 여러 장 한꺼번에, 자동 반복, 자동 재시도 (NovelAI는 사람이 누른 요청만 허용하고 429에 재시도를 금한다)
- 29스텝 이상, 큰 크기 (Anlas가 드는 범위)
- 인페인트, 바이브·캐릭터 레퍼런스(V5에서 막힘), 인물별 프롬프트, 여러 장 참조, 참조 그림 저장
- 토큰을 내보내기 파일에 넣기
