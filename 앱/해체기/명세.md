# 해체기 — 명세

## 한 줄

RisuAI 파일(.risup 프리셋, .risum 모듈, .charx 카드 묶음, 카드 JSON·PNG, 하이파 설정, 플러그인 .js, zip)을 폰에서 열어 구조를 보여 주고, AI 프롬프트 글 한 덩어리로 뽑아 복사·저장하고, 짤뽑기에 붙여 넣을 글을 칸별로 만들어 준다.

## 데이터 모양

`app.js`의 `SHAPE()`와 같아야 한다. 저장하는 것은 조립 설정뿐이다(localStorage `해체기/v1`). 불러온 파일은 크기가 커서(예: 카드 1MB, 압축 풀면 수 MB) 저장하지 않고 메모리에만 둔다. 새로 고치면 불러온 파일은 사라진다.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| settings | slots / headers / strip / lore | slots: 프리셋의 RisuAI 슬롯을 `[[이름]]`으로 표시(`mark`)할지 비울지(`blank`). headers: 블록 이름 줄을 넣는지. strip: 로어북 지시어 줄(`@@depth` 등)을 지우는지. lore: 카드·모듈의 로어북을 이어 붙이는지 |
| (메모리) files | 노드 `{id, name, size, kind, label, body?, text?, children?, note?}` | 불러온 파일. kind는 preset·module·card·hypa·plugin·zip·json·text·binary·error |

옛 데이터는 없다(새 앱). 설정에 칸이 빠져 있어도 `load()`가 `settings`를 칸 단위로 기본값과 합쳐 읽는다(부분 설정을 심어 시험함).

## 화면

| 화면 | 주소 | 하는 일 | 쓰는 데이터 |
|---|---|---|---|
| 목록 | `#/list` | 불러온 파일을 묶음별로 보여 주고(압축 안의 파일은 들여쓰기) 누르면 내용으로, ‘이 묶음 닫기’ | files |
| 파일 열기 | `#/add` | 파일 여러 개 고르기. 하나면 바로 내용으로, 여러 개면 목록으로. 첫 화면에 되는 형식 안내 | files |
| 내용 보기 | `#/view/<id>/<탭>` | 탭 셋: **구조**(종류별 표: 프리셋은 모델·블록 순서·정규식·토글, 모듈은 로어북 수·트리거, 카드는 필드 길이·sdData, 플러그인은 머리말·적힌 주소·코드 신호, zip은 안의 파일), **조립 글**(프롬프트 한 덩어리, 앞 12,000자만 보이고 복사·.md 저장은 전체), **짤뽑기로**(카드·모듈만) | files, settings |
| 설정 | `#/settings` | 조립 설정 네 가지, 불러온 파일 모두 닫기, 설정 처음 값으로 | settings |

짤뽑기로 탭: 카드의 `description`·`personality`를 짤뽑기 ‘내 조각’용 글로, 카드 `sdData`를 짤뽑기 칸(1순위 인원수, 3순위 특징, 5순위 포즈, 6순위 배경, 빼는 것)별 글로 복사 버튼과 함께 준다. 로어북 항목은 검색해서 하나씩 ‘내 조각’용으로 복사한다(30개씩).

## 풀이 순서

공개 문서(rescuetycoon/risup)를 따르고 올린 파일로 직접 확인했다. 암호 키 `risupreset`은 그 문서에 있는 값이다.

| 형식 | 순서 |
|---|---|
| .risup | RPack(256바이트 치환표) → gzip → msgpack → (presetVersion 0·2면) AES-256-GCM(SHA-256("risupreset"), iv 0 12바이트) → msgpack |
| .risum | `0x6f 0x00` + 길이(u32 LE) + RPack으로 푼 JSON, 뒤에 에셋 덩어리 |
| .charx | zip: `card.json`(chara_card_v3), `module.risum`, `assets/` |
| PNG 카드 | `tEXt` 청크 `chara`·`ccv3`의 base64 JSON (합성 PNG로만 시험) |
| 플러그인 .js | 글로만 읽음. 머리말(`//@name` 등), 글에 적힌 주소, 코드에 나오는 낱말 횟수를 셈. 실행하지 않음 |

## 밖에 나가는 것

없음. 파일은 이 기기 안에서만 풀린다. 서비스워커가 자기 주소의 파일만 저장한다.

## 지킨 것(터지는 곳)

- 큰 파일: 압축을 풀었을 때 300MB를 넘으면 멈추고, 150MB 넘는 파일은 열지 않는다. zip 안의 zip은 4겹까지.
- 긴 글: 화면에는 앞 12,000자만 그리고 복사는 전체. 로어북 목록은 30개씩.
- 깨진 파일: 빈 파일, 잘린 `.risup`·zip, 아무 바이트, 깨진 JSON은 ‘읽기 실패’나 글로 나오고 앱은 안 죽는다.
- 암호 풀기(`crypto.subtle`)는 https 또는 localhost에서만 된다. 그 밖의 주소에서는 열기 화면에 경고가 뜬다.
- 설정 저장이 실패하면(`localStorage` 예외) 화면 위에 경고가 뜬다.
- 열쇠 칸(`openAIKey`, `proxyKey`)은 값이 있으면 있다는 것만 보이고 값은 안 보여 준다. 다만 조립 글에는 프리셋이 가진 글이 그대로 들어간다.

## 안 하는 것

적어 두면 나중에 흔들리지 않는다.

- 로그인, 서버 저장, 기기 사이 동기화, 불러온 파일을 저장해 두기(새로 고치면 다시 열어야 함)
- RisuAI 매크로(`{{#when::…}}`, `{{getglobalvar::…}}` 등) 풀기. 그대로 둔다. 그래서 조립 글은 RisuAI가 실제로 AI에 보내는 글과 같지 않다
- 로어북을 키워드로 걸러 실제 대화처럼 넣기(전부 이어 붙임)
- 플러그인 실행, 에셋(그림·소리) 꺼내기·보여 주기, .risum 에셋 추출
- 파일 고치기·다시 묶기(읽기 전용)
- 짤뽑기에 직접 보내기(짤뽑기에 가져오기가 없음. 복사해서 붙여 넣기)
- 비공개로 만든 남의 프리셋을 퍼뜨리는 용도

## 확인한 것과 못 한 것 (2026-11-19)

- 확인: 올린 파일 7개(프리셋 4, 하이파 JSON, charx 2, Proton zip 안의 zip·charx·플러그인 JS 2)를 node와 크로미움 390x844에서 열었다. 종류 판별·구조·조립·복사(클립보드 값까지)·.md 저장 버튼 이전 단계·설정 변경이 조립에 반영됨·부분 설정·다크 모드·가로 넘침 0·콘솔 오류 없음.
- 확인 못 함: 실제 폰(키보드, 노치, 터치), 파일 선택창이 폰에서 `.risup` 같은 낯선 확장자를 보여 주는지, 서비스워커의 다음 방문 동작, PNG 카드는 합성 PNG로만 시험(실제 RisuAI PNG 카드는 못 봄), 로어북 지시어 지우기 결과, `.md` 저장(파일로 내려받아 열어 보지 않음), 매크로를 푼 결과가 RisuAI와 같은지(풀지 않음).
