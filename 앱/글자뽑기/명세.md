# 글자뽑기 — 명세

## 한 줄

긴 스크린샷을 넣으면 글자만 뽑아 복사하게 해 준다.

## 데이터 모양

`app.js`의 `SHAPE()`와 같아야 한다.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| items[] | id / at / text / pieces | 뽑은 글 하나. `pieces`는 그림을 자른 조각 수. 그림은 저장하지 않는다 |
| settings | apiKey / model | 제미니 API 열쇠, 모델 이름 |

## 화면

| 화면 | 주소 | 하는 일 | 쓰는 데이터 |
|---|---|---|---|
| 뽑기 | `#/pick` | 그림 고르기 → 자르기 → 조각마다 제미니가 받아 적기 → 이어 붙여 보여 주기, 복사 | settings, items |
| 기록 | `#/list` | 뽑았던 글 목록, 복사, 지우기 | items |
| 기록 하나 | `#/view/<id>` | 글 하나를 보고 고치고 복사 | items |
| 설정 | `#/settings` | 열쇠, 모델, 기록 전부 지우기 | settings, items |

## 자르는 법

- 너비가 1200px를 넘으면 1200px로 줄인다. 높이 1600px씩 자른다.
- 조각 아래쪽 400px에서 가로로 한 색뿐인 줄(글줄 사이 빈 곳)을 찾아 거기서 자른다. 글줄이 반으로 갈리지 않는다.
- 빈 곳이 없으면(사진 위 등) 140px 겹쳐 자르고, 이어 붙일 때 두 번 나온 글을 한 번만 남긴다.
- 조각은 세 개씩 한꺼번에 보낸다. 한도(429)·서버 오류는 두 번 더 해 본다.

## 밖에 나가는 것

고른 그림이 조각으로 잘려 사용자의 열쇠로 제미니 API(`generativelanguage.googleapis.com`)에 간다. 그 밖에는 없다. 뽑은 글과 열쇠는 이 기기 localStorage에만 있다.

## 안 하는 것

- 목소리로 읽기, 요약, 번역 (사용자가 글자만 뽑기로 정함, 2026-11-28)
- 그림 저장
- 로그인, 서버 저장
