# 아이디어지도 — 명세

## 한 줄

아이디어 저장소를 열어 보고, 같은 주제의 원고·인물(글 저장소)과 취향·고정 블록·태그(그림 저장소)를 한 화면에 이어 보며, 거기서 바로 글 초안·인물 카드·NAI 프롬프트를 뽑는다.

## 데이터 모양

`app.js`의 `SHAPE()`와 같아야 한다. 전부 이 기기 localStorage(`아이디어지도/v1`)에만 있다.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| settings | owner / ghToken / geminiKey / model / repos{idea, write, art} | GitHub 계정 이름, 읽기 전용 토큰, 제미니 열쇠, 제미니 모델, 역할별 저장소 이름(설정에서 내 저장소 목록을 불러와 고른다) |
| cache | at / files{경로: 글} / errors[] | 마지막으로 받아 온 시각과 파일 내용. 경로는 `역할/파일경로` (역할: idea·write·art) |
| made[] | id / path / kind / text / at | 뽑은 결과. kind는 글·인물·그림. 30개까지, 오래된 것부터 버림 |

태그 사전(그림 저장소의 `태그사전/다른이름.tsv`, 약 4MB)은 localStorage에 넣지 않고 처음 '태그 찾기'를 누를 때 받아 Cache Storage에 둔다.

## 화면

| 화면 | 주소 | 하는 일 | 쓰는 데이터 |
|---|---|---|---|
| 목록 | `#/list` | 아이디어 저장소 `목록.md` 순서대로 서가·보관소 책을 보여 줌. 위 칸에 글자를 치면 세 저장소 전체에서 찾음 | cache |
| 보기 | `#/view/<저장소>/<경로>` | 책 내용, 이어진 것(같은 낱말이 많이 겹치는 원고·인물·취향·다른 아이디어), 인물 이름이 나오는 NAI 고정 블록, 태그 찾기, 만들기 버튼 셋 | cache, made |
| 만든 것 | `#/made` | 뽑은 결과 목록. 복사·지우기 | made |
| 설정 | `#/settings` | 토큰, 내 저장소 불러와 역할 셋 고르기, 열쇠·모델, 다시 받기, 받은 파일 수 | settings, cache |

## 읽어 오는 파일

- 아이디어 저장소: `목록.md`, `서가/**/*.md`, `아이디어보관소/*.md`
- 글 저장소: `novel/WORKS.md`, `novel/TASTE.md`, `novel/works/*/` 아래 `인물.md`·`투입카드.md`·`story-bible.md`·`00_canon.md`
- 그림 저장소: `취향.md`, `프롬프트/NAI.md`, `참고/*.md`
- **절대 안 읽는 곳 (벽 안쪽):** 아이디어 저장소의 `일기/`, `감정배설/`, `진료/`, `사서참고.md`, 그리고 `생활/`, `입고기록/`. 목록을 받을 때 걸러 내고, 화면에 그릴 때 한 번 더 걸러 낸다

## 밖에 나가는 것

- `GET https://api.github.com/user`, `/user/repos` — 설정에서 저장소 목록 불러오기
- `GET https://api.github.com/repos/<계정>/<저장소>/git/trees/HEAD?recursive=1` — 파일 목록
- `GET https://api.github.com/repos/<계정>/<저장소>/contents/<경로>` (`Accept: application/vnd.github.raw`) — 파일 내용. 토큰은 `Authorization: Bearer`. 토큰은 Contents 읽기 권한만 있는 fine-grained 토큰을 쓴다
- `POST https://generativelanguage.googleapis.com/v1beta/models/<모델>:generateContent` — 만들기 버튼. 열쇠는 `x-goog-api-key`. 보내는 것은 그 책 내용과 글 저장소 `TASTE.md` 또는 그림 저장소 `취향.md`·`NAI.md`뿐이다

## 안 하는 것

- 저장소에 쓰기. 뽑은 결과는 복사해서 Claude에게 넣어 달라고 한다 (아이디어 저장소의 사서 규칙과 `[가안]` 표시를 거쳐야 하므로)
- 벽 안쪽 읽기
- 여러 기기 동기화
