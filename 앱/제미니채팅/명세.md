# 제미니채팅 — 명세

## 한 줄

제미니 API와 1대1로 대화한다. 시스템 프롬프트는 길이 제한 없이 마음대로 적고, 조절 가능한 안전 필터는 전부 끈다.

## 데이터 모양

`app.js`의 `SHAPE()`와 같아야 한다.

| 덩어리 | 칸 | 뜻 |
|---|---|---|
| messages[] | id / role / text / at / err? / note? / cut? | 말 하나. role은 user 또는 model |
| settings | apiKey / model / system / temperature | 열쇠, 모델 이름, 시스템 프롬프트, 온도 |

## 화면

| 화면 | 주소 | 하는 일 | 쓰는 데이터 |
|---|---|---|---|
| 대화 | `#/chat` | 말 보내기, 답을 흘려 받기(스트리밍), 멈추기, 다시, 복사 | messages, settings |
| 설정 | `#/settings` | 열쇠·모델·시스템 프롬프트·온도, 모델 목록 불러오기, 내보내기, 대화 지우기 | settings, messages |

## 밖에 나가는 것

- `generativelanguage.googleapis.com` — `streamGenerateContent?alt=sse`, `models` 목록. 헤더 `x-goog-api-key`에 사용자가 넣은 열쇠.
- 안전 필터: HARASSMENT, HATE_SPEECH, SEXUALLY_EXPLICIT, DANGEROUS_CONTENT, CIVIC_INTEGRITY 전부 `OFF`. 아동 안전 같은 핵심 보호는 API 쪽에서 늘 막히고 끌 수 없다 ([문서](https://ai.google.dev/gemini-api/docs/safety-settings), 2026-11-12 확인).

## 안 하는 것

- 로그인, 서버 저장, 여러 대화방 (대화는 하나)
- 열쇠를 저장소나 서버에 두기 — 사용자 폰 localStorage에만
- 마크다운 렌더 (글자 그대로 보여 줌)
- 이미지·파일 올리기
